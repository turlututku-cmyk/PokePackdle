# PokePackdle

A pack-opening RNG race in a single HTML file. Rip a 10-card pack, flip the cards, and race for your best score.

- **Random every time.** Each run is a fresh pack, saved so a reload can't reroll cards you've already seen.
- **Cards score from their own stats:** HP, attack damage, energy efficiency, type, weakness, resistance, retreat cost, evolution stage and card type.
- **Badges** for what a whole pack looks like (twins, a rainbow of rarities, a shiny, total HP and more).
- **Accounts, stats and a leaderboard** that live in your browser's local storage (no server).
- **Sound effects** synthesised in the browser.

## Run it

Open `index.html` in a browser. It needs an internet connection to load creature stats and moves.
